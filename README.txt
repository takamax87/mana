赤坂麻凪さん 活動まとめ（試作版）

使い方：
1. このフォルダ一式をHTTPS対応のWebサーバーにアップロードします（GitHub Pages等）。
2. iPhoneのSafariで公開URLを開きます。
3. 共有ボタン →「ホーム画面に追加」でアイコンから起動できます。

機能：
- 出演作品の登録・検索・並べ替え
- 観劇済みチェック
- 共演者の作品数ランキング自動集計
- データは利用中のブラウザ内（localStorage）に保存

注意：
- 現段階は試作版です。データは端末・ブラウザ間で同期されません。
- 初期データは入っていません。作品情報を確認しながら登録してください。
- 公開時はHTTPSが必要です。
